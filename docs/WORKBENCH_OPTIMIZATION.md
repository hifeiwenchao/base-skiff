# 工作台优化（2026-11-24）

## 使用

- SQL Console 运行按钮在运行期间变为「中断查询」；每个 Console/工作区持有自己的取消令牌。SSH 与直连均传递令牌，驱动取消在后台执行。到达提交阶段后等待数据库确认结果，避免已提交的写入被误报取消。数据库的隐式提交（例如部分 DDL）仍由具体数据库决定。
- 普通 SQL 连接打开表默认不统计总数，先读取一页和一条探测记录。页脚「统计总数」可开启精确统计；示例库保留原有统计。默认单主键升序使用游标续页，其他排序/复合键使用 OFFSET；刷新/条件变化清除旧游标。并发写入期间跨页读取并不保证快照一致。
- Console 顶部 SQL 菜单提供当前语句执行、格式化、执行计划、刷新提示缓存、多个命名 Console、打开/保存 SQL 文件。默认运行和现有快捷键保留选区优先、无选区全文的行为。输入时自动补全及 Ctrl+Space 只读取本地缓存。首次 Console 可按需加载表名和前 30 张表的字段；打开其他表会补其字段缓存。格式化为保守的词法格式化，不提供完整语法诊断和自动纠错；别名解析支持简单未引用别名。
- 表右键 → 表结构操作 → 修改表结构：左侧字段/索引，右侧属性，下方 SQL 预览。先暂存，再点击应用。支持新增字段、字段改名、适用方言的类型修改、字段删除、索引创建删除。主键/约束索引受保护。SQLite 类型修改和 MySQL 类型重建被禁用（需要完整字段元数据）。失败后锁定草稿，关闭后重新打开检查实际结构。多条 DDL 可能部分提交，界面明确显示已完成条数。
- 导出按钮区分当前显示数据和数据库全部结果。SQL 全量 CSV 导出捕获当前表的已提交筛选/排序，或 Console 当前选区/语句，后台分批读取，显示行数并允许取消。成功后原子替换目标文件；失败/取消删除临时文件。查询导出和执行计划只接受单条 SELECT。SQLite/PostgreSQL/MySQL 提供非 ANALYZE 执行计划；Oracle 暂不提供写计划表的流程。
- 每个连接可设置查询超时（秒），默认 10 秒。不同驱动的超时语义有所不同，连接建立仍使用独立连接超时。
- 重启恢复表/集合/Redis key 标签及顺序、筛选排序、活动标签或命名 Console；仅当前标签按需查询。结果、凭据及待提交网格修改不写入工作区描述。退出存在待提交修改会提示；取消退出保留全部草稿。

### 2026-11-25 数量显示修复

关闭总数统计时，如果第一页已包含全部结果（含空表、筛选和恰好满页），直接显示实际总数，不额外执行 COUNT；有后续页时显示「总数未统计 / total not counted」，可点击「统计总数」。游标请求不会把局部结果误报为全表总数。

## 2026-11-26 剩余优化

- Redis：每批新增键直接插入现有树，保留节点、搜索行与展开/滚动状态；Hash/List/Set/ZSet 值页增加「加载更多」，每批最多 1,000 项，已加载项保留。Hash/Set/ZSet 使用 SCAN 并去重，List 使用位置续载；刷新重新开始。作用域绑定连接、DB、原始二进制键与类型。Redis 的 SCAN 是弱一致浏览，同类型键被替换或并发修改时应刷新；Stream 保持 1,000 项只读预览，大 List 删除仍通过命令处理。
- SQL 补全：JOIN、CTE、派生表、schema/带引号标识符按作用域解析；Ctrl+Space 缺少字段时后台加载目标表，不在每次按键查询。刷新清除过期缓存，类型信息仍以服务端实际目录为准。不是完整 SQL 语义分析器；驱动未提供坐标时只显示原始错误，提供坐标时在准确选区/当前语句位置标记。
- MySQL：读取类型、自增、字符集/排序规则、注释、生成表达式等属性，类型修改保留可重建属性；生成列、表达式默认值等无法安全重建的定义保持禁用。外键、主键、唯一约束与 CHECK 在统一窗口预览后应用；SQLite 无原生 ALTER 支持的约束变更明确提示需要重建。目录可查看引用表/字段。
- 分页：复合主键及简单字段排序使用完整排序游标，附加主键打破平局，按数据库原生 NULL 顺序处理。复杂表达式、无主键、MySQL ENUM/SET 等比较语义不匹配的类型回退稳定 OFFSET，避免漏行。跨页仍不持有长事务快照。
- 执行计划：SQLite/PostgreSQL/MySQL/Oracle 结果可显示为原生树及估算详情，显示获取计划耗时；估算不是实际执行耗时。Oracle 需可写 PLAN_TABLE，使用随机 statement_id，仅清理本次计划，原查询不执行。只读 Oracle 连接提示不支持该流程。
- CSV：SQL 全量导出可选 UTF-8、GB18030、UTF-16 等编码、逗号/制表符/分号及 NULL 标记。数据页「导入 CSV」先选格式、预览、映射目标字段，再后台单事务写入；出错/取消回滚，报告行号。预览只读前 20 行，每个字段解析上限 16 MiB，二进制列导入明确拒绝（可跳过）。Oracle DATE 的时分秒保留，ENUM/SET 保持原文。NULL 标记与真实文本相同会被视为 NULL，导入前应选择不会冲突的标记。
- 构建：输出及工作缓存目录成对原子占用，跨不同 dist 共用 work 也不会同秒冲突，保持 build-YYYYMMDDHHMMSS。
