# 剩余优化设计

用户已授权将 2026-11-26 列出的优化项全部实现。延续原生 Python/PySide6、中英文、500 键批次、来源工作区隔离、只读保护与显式提交。

- Redis：新增批次增量挂树，保留已加载叶节点及滚动/展开状态；集合服务端续载，Hash/Set/ZSet SCAN 去重，List 按索引。续载绑定连接/DB/原始键/类型，刷新重新开始；不承诺并发修改期间快照一致。安全编辑规则保持，List 大列表删除继续禁用。
- SQL：补全识别带引号标识符、JOIN/子查询/CTE 的作用域，缓存未命中显式请求异步补充，输入不逐次查询。驱动提供位置时定位错误，无位置不猜测。
- DDL：保存完整 MySQL 字段属性后允许类型修改，保留自增/字符集/排序规则/注释，不能重建的定义明确拒绝；可管理外键、唯一/检查约束并查看关联字段，生成 SQL 后显式应用。SQLite 无法原生修改的约束操作保持说明。
- 查询：复合主键和可确定排序键使用游标并加主键打破平局，NULL 排序安全处理，无法保证一致的表达式排序回退 OFFSET；计划树和耗时概览；Oracle 使用唯一 statement_id 生成/读取/清理自己的计划。
- CSV：选择编码/NULL标记，后台流式导入预览与字段映射，类型转换，单事务写入、失败/取消回滚，保留错误行号。导出继续分批与原子替换。只读连接禁止导入。
- 构建：输出与 work 目录都原子占用，保持 build-YYYYMMDDHHMMSS，处理跨输出目录共享 work 碰撞。
- 验证：临时真实数据库专用对象、单元/Qt回归、性能对比、三平台CI可用则核验；本机只可构建 macOS，不将脚本模拟当作 Windows/Linux 实机。所有改动本地打包。
