# BaseSkiff design

Python 3.11+ and PySide6 provide a native desktop application for macOS, Windows and Linux. PyInstaller runs on each target OS; this Mac produces a local arm64 application. Chinese and English switch immediately and persist using QSettings.

The application has a compact connection sidebar, searchable table tree, top breadcrumb, data/query/structure tabs, row toolbar, paginated data grid, optional record inspector, operation history and connection overview. A warm white and sage palette, thin dividers, readable monospace cells and custom line icons form the visual system. Empty, working, failure and disconnected states are explicit.

Adapters run outside the GUI thread. Python standard sqlite3 supplies an actual local sample SQLite database; PyMySQL, psycopg, PyMongo, redis-py and python-oracledb thin mode support external databases. The user supplies real server credentials. SQL adapters quote identifiers and bind values. Tables without primary keys are read-only in the grid. MongoDB uses JSON command objects; Redis uses shell-style commands. Read-only connections block mutations and query execution except explicitly allowed reads.

Connection metadata and history live in the OS application-data directory. Database passwords, SSH passwords and key passphrases persist locally with Fernet encryption in metadata.sqlite; credentials.key holds the local encryption key. Both files are restricted to the current user on POSIX. The application does not access the system keyring. Editing with blank secrets preserves local values; deleting a connection removes its credential records. History records success/failure, query, rows, time and connection. SQL/command history can contain user-entered sensitive literals and is clearable. Editing and deleting records require explicit save/confirmation.

The local sample has customers, products, orders, order_items, categories and activity_log, with consistent fictional data. All sample CRUD is real SQLite. No external connection is simulated. CSV export writes the currently displayed result. Queries are limited to 1000 result rows; table browsing uses pagination. Backups, cloud sync, ER diagrams and signed distribution are outside version 0.1.

Network connections support per-operation Paramiko SSH tunnels with password, private-key or SSH agent authentication. Host identity is verified against known_hosts or an explicit SHA256 fingerprint before authentication. SSH passwords and key passphrases use separate encrypted local entries. The native bilingual connection dialog has Database and SSH tunnel tabs. MongoDB tunnels use a single direct target without replica discovery. SQLite remains local.

Tests exercise real SQLite CRUD, queries, rollback on errors, history persistence, read-only enforcement, quoting, filtering and pagination. Qt tests verify startup, page changes, language switching and CRUD dialogs. Real local MySQL, Redis and MongoDB are also exercised directly and through an ephemeral local SSH server, including native Qt workflows. The actual Mac application is packaged and smoke-tested. PostgreSQL, Oracle, external bastions and Windows/Linux builds remain outside the live validation performed here.
