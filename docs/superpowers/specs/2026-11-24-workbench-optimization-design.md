# BaseSkiff 工作台优化设计

用户已确认按代码审查建议实施。沿用 Python/PySide6、中文/英文、六种数据源和本地凭据；每轮功能变更在本地打包。

## 实施方式
分模块增量改进现有工作台，保持已有网格待提交事务和 Redis 每批 500 个键的规则。与整体重写相比，复用已验证的连接、异步任务和多标签状态更容易回归；不引入 Web 前端。

## 范围
1. 查询取消：令牌按工作区归属，SSH 透传，取消不阻塞 UI，提交前检查，迟到结果隔离。
2. 大表：可选择不统计总数，额外读取一行判断下一页；默认先显示数据，保留按需精确统计。安全可行的单主键默认排序使用游标，其他排序保留 OFFSET。
3. SQL 编辑：缓存元数据补全表名/字段/关键字、格式化和当前语句执行；保留选区优先和全文执行入口。
4. 结构：统一字段/索引属性窗口、变更草稿、生成 SQL 预览和显式应用；删除表保留输入表名和二次确认，删除索引只确认一次。
5. 全量导出：后台分批 CSV、取消、进度、临时文件成功后替换目标，避免加载整个结果或覆盖失败文件。
6. 恢复：恢复打开的对象/顺序/筛选/排序和活动标签，恢复时按需加载；不恢复查询结果、运行中的任务或自动提交待提交修改。
7. 排障：执行计划入口和可配置查询超时。Redis 的累计节点与大集合按需加载依据测量优化，避免未经测量的整体树重写。

## 验证
新增行为回归测试、现有全套测试、静态检查、源码及打包启动检查。没有运行的真实服务和其他操作系统不能声明已验证。
