## 边界与发布状态

原生入口独立保留，尚不替换现有 macOS 默认发行入口。以下范围不能宣称已完成实机认证：所有 SSH 认证 / TLS 组合的原生表单操作、Intel Mac、macOS 14 目标系统、辅助功能读屏及所有缩放 / 多显示器组合。已有 Python 集成测试覆盖的行为不等于这些原生 UI 路径都已点击验证。

SQL 错误高亮仅采用驱动提供的可靠坐标；全文来源可确定时高亮原文，选区 / 当前语句不能可靠定位到原文时显示相对于执行语句的行列，不猜测位置。预览和传输大小限制见原生使用说明。

最终本机测试数量、构建路径及截图在工作完成后的验证记录中填写；不把历史测试结果当作本轮结果。
